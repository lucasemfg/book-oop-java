# 📘 Book OOP Java

Projeto simples em Java que demonstra os princípios da **Programação Orientada a Objetos (POO)** na prática.  
O sistema simula a interação entre pessoas e livros, permitindo **abrir**, **folhear**, **avançar** e **retroceder** páginas de um livro — ideal para quem está iniciando em Java e quer exemplificar o uso de classes, objetos, encapsulamento e interfaces. :contentReference[oaicite:0]{index=0}

---

## 🚀 Sobre o Projeto

Este projeto foi criado com os seguintes objetivos:

- 💡 Aprender e aplicar os conceitos fundamentais de POO em Java;
- 🧠 Entender a estrutura de um projeto Java básico;
- 📚 Simular operações comuns relacionadas a livros e leitura;
- ✨ Demonstrar boas práticas de organização de código.
